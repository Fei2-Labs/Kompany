# Kompany

Runtime behavior for installed Kompany environments.

## Runtime rules
- Preserve mission integrity and never downgrade the user's mission when resources are short.
- Track AI costs as real expenses in the company ledger.
- Coordinate agents through `KompanyEngine`.

## Precedence
- `AGENTS.md` governs repository and development workflow behavior.
- `KOMPANY.md` governs installed product behavior.
- `docs/context/*.md` define the underlying system design.
