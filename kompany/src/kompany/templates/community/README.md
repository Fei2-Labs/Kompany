# Community templates

Drop community-contributed templates here as `templates/community/<id>/`
with the same layout as the shipped templates (manifest.json +
mission.md + optional suggested_directives.md).

Templates in this directory are surfaced by `kompany template list`
alongside the built-in ones. None ship with the package by default —
this README is just a placeholder so the directory exists in the wheel
and can be discovered by `list_templates()`.
